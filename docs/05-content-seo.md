# Content / SEO System

- Define intent and keyword cluster per service, industry and solution.
- Use unique titles, metas, h1, service deliverables, FAQs and internal links.
- Canonical URLs and review-gated hreflang by language.
- Organization, Service, BreadcrumbList, Article and FAQ structured data only when eligible and matching visible content.
- Create original case studies with approved client data and references.
- Only enable public blog content when `published: true` and fact checked.
- 4 language architecture: en, fr, ar (RTL), zh. Currently English only published.
- Sitemap must exclude private endpoints, empty draft routes and unreviewed translations.
- Keep semantic HTML and crawlable copy outside WebGL canvases.
